Rules:
- Contracts may depend on Platform Contracts, never on another module's internals.
- Modules depend on other modules' Contracts only when declared (Pets/Vehicles -> Documents).
- Integration handlers depend on Contracts, not persistence models.
- SQL foreign keys across boundaries protect integrity and do not confer query ownership.
- No Repository interface per Eloquent model by default; add ports at real replacement boundaries.
- Shared UI is imported by modules. Modules do not import another module's pages/hooks.
