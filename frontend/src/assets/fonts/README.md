# Fonturi

Fonturile variabile sunt incluse local. Aplicația nu solicită fonturi unui serviciu extern.

- Nunito — [sursa Google Fonts](https://github.com/google/fonts/tree/main/ofl/nunito), licență în `Nunito-OFL.txt`.
- Fraunces — [sursa Google Fonts](https://github.com/google/fonts/tree/main/ofl/fraunces), licență în `Fraunces-OFL.txt`.

Fișierele TTF originale, fără subsetare sau modificări, au fost preluate la 23 octombrie 2026. Ambele au licența SIL Open Font License 1.1.
